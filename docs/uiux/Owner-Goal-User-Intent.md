# Owner Goal ↔ User Intent — Violet V4

| Owner goal | User intent | Meeting point in experience | Evidence / decision object | Conversion |
|---|---|---|---|---|
| Establish Violet as a serious curator | “Show me why this edit is worth trusting” | Houses + visible curation logic | maison provenance, sample policy, curated selection | open house/PDP |
| Reduce marketplace overload | “Help me narrow without knowing everything” | Home routes + PLP + Scent Portrait | mood/family/presence, concise shortlist | filter / portrait |
| Make sampling a core differentiator | “I do not want to blind-buy” | Discovery route + PDP buying desk | sample eligibility, build-a-trio, discovery sets | add sample/discovery |
| Encourage confident full-bottle purchase | “Is this fragrance right for me?” | PDP | object media, scent character, notes, presence, wearing context, house trust | add full bottle |
| Support multi-house exploration | “What else does this maison represent?” | House index/detail | house story + collection + discovery entry | browse house |
| Preserve calm luxury | “Do not pressure me” | entire buyer journey | transparent pricing, no fake scarcity/countdown, quiet controls | checkout when ready |

## Priority journey

`Entry → choose route (Fragrance / House / Discovery / Portrait) → narrow → evaluate scent → sample or full bottle → bag → simulated checkout`

## Recovery journey

- No filter results → remove one filter / clear all / Scent Portrait.
- Portrait uncertainty → build sample trio rather than forcing full bottle.
- PDP uncertainty → sample/discovery path at same decision layer as full bottle.
- Empty cart → return to edit/discovery, not generic homepage only.

## Owner-message discipline

V4 should demonstrate these messages structurally instead of repeating them in copy:
- curated = fewer, reasoned objects and houses;
- trusted = provenance + explicit system reality;
- luxury = confident media, typography and restraint;
- discovery = actual low-commitment path, not a slogan.
