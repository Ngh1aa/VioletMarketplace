# Current Site Audit — V3 baseline

## Overall
V3 is technically coherent and visually competent, but it still reads as a carefully styled prototype more than a mature luxury multi-house fragrance destination. The main gap is structural/product authority, not CSS cleanliness.

## KEEP
- Violet name, warm ivory/lilac/aubergine world and restrained serif/sans rhythm.
- Strong desktop hero proportions and low-noise top navigation.
- Scent Portrait as a signature assisted-discovery entry point.
- URL-persistent PLP refinement and clear-all/recovery behavior.
- PDP provenance, olfactive information and honest try-first language.
- LocalStorage cart continuity and explicit simulated checkout reality.
- No sale-timer/marketplace-pressure aesthetic.

## IMPROVE
### Business / conversion
- Sampling is not a continuous journey; it is mostly a Discovery SKU and a generic `Try first` route.
- House curation exists as copy but not as a navigable product dimension with meaningful house pages.
- Product-card copy is longer than needed for high-end browse; key decision information competes with editorial character text.

### Audience / top tasks
- Users who know only mood/occasion still need Scent Portrait; PLP does not surface mood as a primary quick-entry above the grid.
- Expert shoppers need easier house/format/sample comparison.
- Gift buyers have only a category, not a guided gifting path.

### IA / navigation
- Current nav is category-heavy and omits Houses and a first-class Discovery destination.
- `Scent concierge` is a utility link but the assisted journey is not integrated into the whole storefront IA.

### Content
- Homepage contains multiple explanatory manifesto/method sections. The site repeatedly tells users it is curated instead of proving curation through product/media/service structure.
- Trust strip is generic relative to what multi-house fragrance buyers need: official-house provenance, sample policy, fulfilment reality and returns/system scope.

### Brand / visual grammar
- Recognition still depends heavily on purple/lilac + serif. Media world is not proprietary enough to carry brand memory independently.
- Repeated three-card product grids create template rhythm despite improved styling.
- The V3 `03 / Smell the structure...` block is visually distinctive but functions more like a design manifesto than a decision surface.

### PLP
- Good filtering mechanics; composition still resembles `filter rail + three-column catalog` for most of the page.
- Card character paragraph increases density and reduces image/product authority.
- No editorial interruptions, house spotlight or sampling cue inside browse.

### PDP
- Good dossier structure, but five numbered story sections make the page feel documentation-heavy.
- Full-bottle/sample decision is not modeled as a true format choice for each fragrance.
- Related items are reasoned but still visually another three-card block.

### Media
- Remote stock/prototype photography is improved but still mixed-source and not a final controlled campaign family.
- Hero visual world and product still-life world are related by color treatment more than by a clear photography brief.

### Interaction / states
- PLP recovery and cart state are solid for prototype scope.
- Missing post-sample state: save evaluation, liked/disliked, refine shortlist, revisit full bottle.
- No saved wishlist/profile; do not invent until scope explicitly supports it.

### Accessibility / browser
- Existing QA covers headings, overflow, focus basics and Chromium desktop representative routes; formal conformance is not claimed.

## REMOVE / REDUCE
- Reduce brand-explainer manifesto copy on homepage.
- Remove repeated generic product-section shells where one curated composition can do more.
- Remove card-level prose that duplicates PDP content.
- Avoid new decorative gradient/glass layers.

## ADD
- Houses as first-class IA and a distinct page role.
- Discovery hub that connects finder → sample set → wear/evaluate → full bottle.
- Editorial merchandising interruption in PLP.
- Product format/sample decision model with truthful prototype labels.
- Stronger media family/crop ownership and a lower dependence on lavender surfaces for recognition.
