# Responsive and Browser Strategy — Violet V4

## Declared scope
`desktop_only`.

### DUE NOW desktop viewports
- 1280×900 — lower desktop pressure point.
- 1440×1000 — primary review viewport.
- 1600×1000 — wider pressure point retained from current verified profile.

The Prompt 0 template mentioned 1920 as an example desktop viewport, but project truth and current operating profile own the actual V4 scope. 1920 is optional exploratory evidence, not a Phase 1/2 blocker.

### N/A_JUSTIFIED
- tablet: outside current visual-completion scope.
- mobile: outside current visual-completion scope.

Existing smaller-screen behavior should not be intentionally broken, but no claim of `fully responsive` is allowed.

## Browser
- Chromium: DUE NOW for rendered implementation/QA.
- Other browsers: PENDING_FUTURE_PHASE unless project mode/authorization is later raised toward production candidate.

## Desktop transformation rules
### 1280
- Preserve hierarchy; reduce lateral whitespace before reducing product/media authority.
- Home diptych may tighten column ratio but must not collapse into a generic stacked hero.
- PLP refinement and three/product shelf must avoid text compression and horizontal overflow.
- PDP must retain two-column decision composition when usable; compact info spacing before reducing media below meaningful authority.

### 1440
Canonical composition and screenshot comparison viewport.

### 1600
- Increase canvas/negative space; do not simply stretch text lines or images edge-to-edge.
- Product cards/media should cap readable widths.
- Editorial interruptions can use more asymmetry/negative space.

## Sticky/fixed behavior
- Header/filter/PDP sticky owners must be tested for overlap at all three viewport widths.
- No fixed element may obscure a decision action or heading.

## Type/media pressure
- Headings must not orphan single words because of rigid widths where avoidable.
- Product/house names and Vietnamese copy must handle longer text without clipping.
- Image object-position/crop is reviewed separately at 1280/1440/1600 for media-heavy owners.

## Evidence
Phase 2 representative screenshots: all 4 representative roles at 1440; top/critical pressure captures at 1280/1600 for Home, PLP, PDP, Discovery. Prompt 3 extends to all primary buyer roles.
