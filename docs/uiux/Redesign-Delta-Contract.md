# Redesign Delta Contract — Violet V3 → V4

V4 must be visibly and behaviorally structural. If the implementation is primarily palette, typography, spacing, radius, gradient or image replacement inside V3 layouts, the representative-page gate FAILS.

## Global

| Dimension | V3 | Required V4 delta |
|---|---|---|
| Navigation | fragrance categories dominate | task-led `Fragrances / Houses / Discovery / Scent Portrait` + search utility |
| Brand proof | repeated curation/philosophy copy | maison structure, sampling behavior, provenance and edit decisions demonstrate curation |

## Homepage

V3: large hero + family shortcuts + Violet Method + manifesto + family grid + three product-grid sections + concierge + trust strip.

V4 required:
1. one decisive featured object/campaign top;
2. three route choices (Fragrance / Portrait / Discovery) rather than eight equal category shortcuts;
3. curated house index/feature early;
4. one varied curated shelf with editorial interruption, not three same-silhouette grids;
5. discovery ritual as a real next-step module;
6. condensed trust/footer.

At least two V3 explanatory sections must be REMOVED or merged; visible structure cannot remain one-to-one.

## PLP

V3: large explanatory gradient hero + filter rail + uniform 3-column grid with long descriptive card bodies.

V4 required:
- compact catalogue masthead; results become visible sooner;
- filters preserve V3 functionality, add house/sample only if data supports it;
- card body shortened to decision essentials;
- sample/discovery cue visible;
- at least one editorial/house interruption changes the repeated result silhouette without hiding products;
- empty/filter recovery preserved.

## PDP

V3: one large image left + long multi-section dossier right; try-first secondary; house story weak.

V4 required:
- product media/gallery and **buying desk** are the top composition;
- sample/discovery and full-bottle choices are peers in commitment hierarchy;
- size/price/availability are unambiguous before story;
- notes/wearing/curation/house move into clear lower information families rather than equal stacked annotations;
- house is a navigable object;
- related scents remain reasoned but use V4 object-study cards.

## Scent Portrait

V3: 4-step consultation → three recommendations → PDP.

V4 required:
- preserve reversible 4-step logic;
- reduce passive story-panel footprint;
- result state offers sample-trio continuation;
- no AI/self-learning claim;
- local/state behavior remains explainable.

## New page roles

### Houses
V3 has no buyer-facing house index/detail. V4 adds a text-forward house index and page-specific house detail composition.

### Discovery
V3 treats discovery mainly as category/SKU. V4 adds a dedicated low-commitment journey that connects browse/portrait to sample selection and eventual PDP/full bottle.

## Cart/checkout

Only shared-brand polish and sample-item compatibility are expected. Their utility-first structure should remain familiar.
