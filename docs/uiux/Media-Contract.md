# Media / Focal-Point Contract — Violet V4

## Reality boundary

Current remote product photography is **PROTOTYPE MEDIA**. It is not evidence of final licensing, fictional-maison packaging or real campaign ownership. V4 may use carefully screened brand-neutral sources but must not claim them as final production assets.

## Media families

| Family | Purpose | Target ratio | Fit strategy | Focal / no-cut rule | V4 treatment |
|---|---|---|---|---|---|
| Home featured object | establish world + featured scent | 16:10 / 3:2 | cover only with verified safe zone; otherwise contained composite | full bottle/primary object not cut; copy safe zone separate | tactile glass/stone/paper, controlled violet ink field |
| PLP object | compare products | 4:5 | cover/contain based on asset; deterministic mapping | bottle silhouette/label area remains legible/intentional | consistent object scale, quiet background |

| PDP detail | texture/material/alternate angle | 1:1 / 4:5 | crop allowed if explicitly a detail | intentional crop must not masquerade as full object | material/label/cap detail only when source supports it |
| House | communicate scent world | 3:4 / 4:5 | role-specific | material/scene focal point, not random bottle duplicate | texture, archive, botanicals, glass, shadow |
| Discovery | explain trial ritual | 4:3 / 3:2 | content-aware | vial/set/hand action stays intact | tabletop/vials/paper ritual, restrained human presence |

## Photography direction

- Subject: fragrance object, vial/set, tactile material, controlled hand/ritual when useful.
- Lighting: directional soft daylight / warm side light; shadows allowed; avoid overexposed pastel fog.
- Camera distance: consistent product scale in PLP; closer detail only on PDP/editorial.
- Composition: negative space with deliberate asymmetry.
- Background: paper, stone, glass, silk/cloth, simple architectural/material fields.
- Color: warm neutral base with violet/blush reflected tone; never neon purple.
- Avoid: visible third-party branding on fictional products, inconsistent phone/stock looks, busy flowers around every bottle, fake gold luxury cues, duplicate image source in adjacent cards.

## Asset inventory / delivery requirement

During Phase 2 each used asset must have:
`asset URL/source → purpose → rights/status → ratio → focal subject → fit/position → desktop viewports → alt → loading strategy`.

Remote image URLs should request practical dimensions/quality where provider supports it. Reserve aspect ratio to prevent layout shift. Lazy-load below-fold media; first-screen primary media is not lazy by default when it is LCP-critical.

## Crop hard gate

Primary/focal `object-fit: cover` without a documented/verified crop mapping is not allowed to PASS. Phase 2/3 screenshots at 1280, 1440 and 1600 are required for Home feature and PDP primary media.

## Alt rules

- Product object: `<product> by <maison>` when visually informative.
- Decorative texture: empty alt / presentation.
- House/discovery editorial image: describe the meaningful object/ritual, not mood adjectives only.

## Phase-1 limitation

No new V4 assets are selected in Phase 1. Asset replacement is owned by Phase 2 after representative composition proves the required crop families.
