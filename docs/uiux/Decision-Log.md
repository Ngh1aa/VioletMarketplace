# Decision Log — Violet V4 Phase 1

## D01 — Treat V3 as baseline, not foundation to preserve visually
Decision: preserve proven behavior/project truth, but allow major visible restructuring.
Reason: user explicitly judged the current live interface insufficient; Prompt OS requires structural delta rather than sunk-cost preservation.

## D02 — V4 north star
Decision: `private fragrance library with a sampling ritual`.
Reason: aligns Violet’s multi-house marketplace reality with the strongest recurring reference behavior: house authority + sampling + guided discovery.

## D03 — Make Houses and Discovery first-class IA
Decision: add dedicated buyer roles/routes for Houses and Discovery.
Reason: curation and try-before-bottle are differentiators that V3 only expressed through copy/category/SKU.

## D04 — Keep Scent Portrait, change its destination
Decision: preserve four concrete reversible questions and deterministic scoring; connect results to discovery/sample path.
Reason: Finder is V3’s strongest distinctive interaction but currently ends too early.

## D05 — Reject literal design-intelligence luxury recipe
Decision: reject Glassmorphism/Liquid Glass and literal gold despite pinned corpus luxury candidates.
Reason: conflicts with Violet project truth/anti-patterns and would produce generic premium styling. Adopt only media authority/strong hierarchy intent.

## D06 — Use editorial composition selectively
Decision: adapt Editorial Grid/Magazine for Home/House/editorial interruptions; not the entire PLP.
Reason: corpus itself marks ecommerce catalogs as a poor universal fit; cross-page role differentiation matters more.

## D07 — Reduce violet coverage
Decision: warm ivory becomes the dominant canvas; violet/lilac becomes rarer signature behavior.
Reason: current recognition depends too heavily on purple. More restrained use should increase intentionality and make media/product authority stronger.

## D08 — No new font import solely to signal luxury
Decision: retain/refine platform-safe serif + UI sans.
Reason: typography already works; V4’s root problem is structural/media, not lack of a fashionable font. Avoid external dependency for cosmetic gain.

## D09 — Product card content becomes concise
Decision: move long scent character prose to PDP; PLP cards prioritize house/name/format/key scent cue/price.
Reason: improves scan and gives media/product object authority.

## D10 — Local sample evaluation is allowed only as explicit simulation
Decision: Phase2 may add localStorage reaction state if it helps prove the closed-loop journey.
Reason: demonstrates interaction architecture without pretending to have accounts or adaptive AI.

## D11 — Release authority for V4
Decision: merge_and_deploy only after Prompt3 Final QA PASS; Prompt4 production smoke is mandatory.
Reason: user authorized the full workflow and the earlier stale Pages incident demonstrates deploy-success alone is insufficient.

## D12 — Desktop widths
Decision: 1280/1440/1600 are due-now; 1920 optional.
Reason: project operating profile owns actual scope; user’s Prompt0 1920 entry is a configurable template, not higher-priority than current project truth.

## D13 — Seller/admin are not V4 visual redesign roles
Decision: buyer experience is current scope; seller/admin get regression only if shared changes affect them.
Reason: keeps smallest useful graph and aligns user’s dissatisfaction with public storefront.
