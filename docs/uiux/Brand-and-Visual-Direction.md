# Brand and Visual Direction — Violet V4

## Working direction

**Violet Editions — an archival perfume library inside a contemporary gallery.**

The marketplace should feel edited, tactile and informed — less “purple luxury ecommerce”, more a private perfumery where bottles, houses and trial rituals are catalogued with calm authority.

## Seven visual attributes

1. **Object-led** — fragrance object/media outranks decorative copy.
2. **Editorial-indexed** — small numbering, labels and thin rules organize information like an archive.
3. **Warm-paper** — ivory/paper is the dominant field; violet is ink/accent, not wallpaper.
4. **Asymmetric** — intentional offset/spanning modules break card-grid monotony.
5. **Tactile-light** — media uses stone, glass, skin, paper, translucent shadow; not generic pastel fog.
6. **Quietly commercial** — price/sample/full-bottle actions are clear and conventional, never hidden for aesthetics.
7. **Multi-house authoritative** — maison identity and curation are visible across Home/PLP/PDP.

## Layout grammar

- Desktop 12-column system, max content width ~1360px at 1440.
- Main rhythm alternates dense decision zones and generous editorial pauses.
- Thin rules replace most boxes/cards.
- Asymmetric spans (5/7, 4/8, 7/5) are preferred for feature modules.
- Product grids may use 3 columns beside a filter rail, but must include house/editorial interruptions; Home must not stack repeated 3-card shelves.
- Utility pages stay simpler and more symmetric.

## Color role map

- `Paper / Warm Ivory #F7F3EE` — dominant canvas (~55–65%).
- `Violet Ink #241B26` — text, footer, deep orientation fields (~20–25%).
- `Aubergine #55364F` — primary action, active filter, key rule (~7–10%).
- `Quiet Lilac #D9CCD9` — discovery/consultation fields (~5–8%).
- `Warm Blush #E8D6CF` — selective editorial light/skin warmth (~3–5%).
- `Electric Violet #75458A` — rare focus/wayfinding accent; never large decorative fill.

No broad decorative gradient is required. Gradient is allowed only when it meaningfully supports a focal media transition and passes visual review.

## Typography behavior

- Display/product names: editorial serif stack (existing local/system serif; no unverified remote font dependency required).
- UI/body: system sans for clarity.
- H1 scale is page-role specific: Home editorial statement can be larger; PLP title is compact; PDP product name is dominant but commerce remains above fold; utility pages restrained.
- Micro labels: uppercase, letterspaced, used for classification and indexing only — not every sentence.
- Line lengths target 45–70 characters for body/editorial copy.

## Media direction

- Product: object study, clean focal silhouette, tactile material context, 4:5 catalogue ratio.
- Editorial/home: wider 16:10 / 3:2 frame, room for copy safe zone without covering product.
- House: vertical/portrait or material detail that suggests house mood; not the same bottle crop reused.
- Discovery: vials/sets/ritual objects, hands or tabletop when source quality supports it.
- Secondary PDP: deliberate alternate crop/detail, not duplicated image pretending to be a gallery.

## Surface / depth

- Radius: near-zero / small only for functional controls where needed.
- Shadow: rare; use spacing/rules/field contrast before elevation.
- Borders: 1px low-contrast paper/ink rules.
- CTA: filled aubergine primary, paper/ink secondary; square/low-radius, explicit labels.

## Motion

Low intensity. Purpose only:
- image reveal/hover as small crop/scale feedback;
- filter/selection state feedback;
- Scent Portrait progress;
- toast/status feedback.

Reduced-motion removes non-essential transforms/transitions.

## Brand signatures

1. **Violet Index** — `V.01`, `HOUSE 03`, `DISCOVERY / 02` numbering used as wayfinding.
2. **Object Study Frame** — media bounded by one thin rule + bottom classification line rather than card chrome.
3. **Split Ink Rule** — a strong aubergine vertical/horizontal rule anchoring active decisions and editorial interruptions.
4. **Archive + sensory language** — structured metadata paired with one restrained sensory serif line.

Recognition test: without logo/header/footer, a cross-page set should still read as Violet through warm-paper fields, aubergine ink rules, object-study media, archive indexing and restrained serif sensory language.

## Do

- let a bottle/house/sample object be the first anchor;
- use page-specific composition;
- place sample/full-bottle decisions where commitment happens;
- show curation structurally;
- keep controls familiar.

## Do not

- use violet gradient as generic luxury decoration;
- repeat centered heading + three rounded cards;
- make every section a manifesto;
- hide commerce behind editorial prose;
- use visible real-brand product photography for fictional Violet products;
- invent awards, perfumer credentials, heritage or official-stockist facts.
