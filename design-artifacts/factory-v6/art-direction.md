# UIUX Factory V6 — Art Direction

## Direction

**Editorial · Tactile · Portable**

Violet should feel like a contemporary fragrance gallery with commerce inside it. The V6 change does not chase novelty for its own sake; it strengthens the existing maison direction and makes every important visual asset reliably portable into Figma.

## Visual signature

1. **Violet Index** — restrained `V.01`, `HOUSE 03`, `DISCOVERY / 02` classification.
2. **Object → Material → Atmosphere** — the recurring media sequence on Home/PDP/house storytelling.
3. **White field + pastel-violet focus** — white and warm paper remain the canvas; pastel violet marks emphasis rather than filling the page.
4. **Drydown pacing** — content unfolds from first impression to slower evaluation instead of endless equal cards.

## Media direction

- Homepage / PDP: target ~70% media / ~30% copy-commerce in the first major composition.
- Product card: image dominates recognition before metadata.
- Product object remains the primary decision visual; material/atmosphere images never masquerade as packshots.
- Use same-origin repository assets for all buyer-facing fragrance/editorial imagery.
- Above-fold primary media is eager; below-fold media may be lazy in normal browsing.
- `?figma=1` forces all page media eager and disables animation/transform/filter effects that can make editable reconstruction brittle.

## Anti-generic rules

- No centered-heading + three-equal-cards section as the default grammar.
- No universal hero across different page roles.
- No gradients/glass/neon as generic luxury shortcuts.
- No oversized rounded containers around every content unit.
- No stock-photo color becoming the brand system.
- No visible third-party branding used as a fictional Violet packshot claim.

## Creative Director gate

KEEP: image scale, whitespace, typographic hierarchy, try-first logic, route-role diversity.

REVISE: third-party image transport; any media that becomes temporary/missing in Figma; any page whose object hierarchy is diluted by UI chrome.

REMOVE: remote Pexels URLs from runtime source after vendoring; non-essential motion in Figma capture mode.
