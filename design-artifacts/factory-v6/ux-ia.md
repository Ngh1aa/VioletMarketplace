# UIUX Factory V6 — UX / IA

## Primary journey

`Explore → Understand → Try → Wear → Return → Commit`

## Information architecture

- Home — editorial entry + featured object + curated edit + route index.
- Fragrance Library — comparison and refinement by family, mood, presence, maison and try-first eligibility.
- Product Detail — object evaluation, scent character, material/atmosphere gallery and trial-vs-bottle decision.
- Discovery — build a representative trio and reduce purchase risk.
- Scent Portrait — guided vocabulary bridge into Discovery, not an AI endpoint.
- Houses / House — discover a maison through a coherent scent territory.
- Bag / Checkout / Success — conventional, calm transaction prototype surfaces.
- Seller / Admin — operational prototype surfaces, visually denser than buyer showroom routes.

## Representative route gate

1. `/index.html`
2. `/search.html`

4. `/discovery.html`

## Interaction contracts

- Filters remain progressive and reversible.
- Product media leads; metadata supports comparison.
- `Try first` remains adjacent to full-bottle conversion when eligible.
- All controls keep familiar semantics and visible focus.
- Browser-local state remains clearly described as prototype behavior.
- Figma capture mode must not change content, IA or decision states; it may only remove motion and force media readiness.
