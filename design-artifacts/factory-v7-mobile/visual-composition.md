# Visual Composition — Representative Mobile Screens

## 390×844 — Home
- first viewport dominated by one fragrance object / material study;
- one sentence thesis;
- three compact discovery routes below, with Scent Portrait first;
- no dense product carousel above the fold.

## 390×844 — Scent Portrait
- progress index pinned to top of content;
- one question at a time;
- options occupy the full width with 48px+ touch area;
- copy remains short enough to avoid a form-survey feel;
- results shift from questionnaire to visual recommendation objects.

## 390×844 — Recommendation result
- image ~55–60% of visible result object;
- reasons displayed as `Why this matches you` immediately after name;
- `Try in trio` is primary when sample-eligible; `View bottle` secondary.

## 390×844 — PDP
- one dominant object image first;
- match explanation before price/actions when profile evidence exists;
- clear label: `Full bottle · 50 ml` vs `Trial sample · prototype trio`;
- sticky bottom action allowed only if it does not cover note/story content.

## 390×844 — Discovery Trio
- three horizontal/stacked numbered slots;
- balance strip directly beneath selected slots;
- similarity warning attached to the conflicting pair, not as a generic toast only;
- `Add prototype trio to bag` appears only at 3/3;
- prototype/redemption boundary visible near CTA.

## 390×844 — After Try
- scent journal composition: small object image + four sentiment choices + optional issue tags;
- saved state confirms that recommendation rules will use this browser-local feedback next time.

## Desktop preservation
Current editorial Home / PLP / PDP compositions stay asymmetric and image-led. New personalization modules are narrow editorial inserts rather than card-grid wrappers.
